# PromptHub

Онлайн-сервис для управления промптами для языковых моделей. Пользователи могут создавать, редактировать, хранить и использовать промпты, изучать техники промпт-инжиниринга, пользоваться готовыми шаблонами и исследовать достижения в области языковых моделей.

## Технологии

- **Next.js 16** (App Router, Turbopack)
- **React 19**
- **TypeScript**
- **Tailwind CSS v4**
- **lucide-react** (иконки)
- **Jest** + **@testing-library/react** (Unit-тесты)
- **Playwright** (E2E-тесты)

## Структура страниц

```
/                          — Главная (герой-секция, карточки функций, популярные промпты)
/catalog                   — Каталог промптов (фильтры, сортировка, поиск)
/catalog/[prompt]          — Детали промпта (подсветка синтаксиса, избранное)
/editor                    — Редактор промптов (редактор + предпросмотр с подсветкой)
/search                    — Поиск промптов (debounce, саджесты, фильтры, сортировка, URL-параметры)
/knowledge                 — База знаний (статьи по промпт-инжинирингу)
/knowledge/[article]       — Статья
/templates                 — Шаблоны промптов (debounce-поиск, фильтры по категориям)
/templates/[template]      — Детали шаблона (подсветка синтаксиса, кнопка «Использовать»)
/research                  — Исследования
/research/[study]          — Детали исследования
/favorites                 — Избранное
/profile                   — Личный кабинет
/profile/my-prompts        — Мои промпты
/profile/my-templates      — Мои шаблоны
/profile/my-templates/create — Создание шаблона (форма + PromptEditor)
/profile/settings          — Настройки (переключатель уведомлений, выбор темы)
/login                     — Авторизация
/register                  — Регистрация
```

## Основные возможности

### Каталог промптов
- Фильтрация по категориям
- Сортировка (рейтинг, популярность, дата)
- Поиск по названию, описанию и тегам
- Добавление/удаление из избранного

### Редактор промптов (`/editor`)
- Двухпанельный интерфейс: редактор + предпросмотр
- Подсветка синтаксиса в реальном времени (заголовки `##`, переменные `{{var}}`, XML-теги, JSON, декораторы `+++`)
- Валидация полей (название ≥3 символов, текст ≥10 символов)
- Кнопки: Новый, Сохранить, Копировать, Форматировать
- Состояния: заблокированная кнопка, сообщение об ошибке, индикатор сохранения

### Поиск (`/search`)
- Debounce-поиск (300мс) с минимальным количеством символов (3)
- Автодополнение (саджесты) с клавиатурной навигацией (стрелки, Enter, Escape)
- Фильтрация по категориям, сортировка результатов
- Параметры поиска сохраняются в URL (?q=...)
- Восстановление результатов из URL при перезагрузке
- AbortController для отмены предыдущих запросов

### Шаблоны (`/templates`)
- Debounce-поиск с саджестами
- Фильтрация по категориям
- Детальная страница с подсветкой синтаксиса
- Кнопка «Использовать шаблон» → переход в редактор

### База знаний (`/knowledge`)
- Статьи по промпт-инжинирингу
- Фильтрация по категориям

### Личный кабинет
- Профиль пользователя со статистикой
- Мои промпты, Мои шаблоны
- Создание шаблонов через `PromptEditor`
- Настройки (переключатель уведомлений, выбор темы)

### Авторизация
- Страницы `/login` и `/register` с формами и валидацией
- Мок-авторизация через localStorage

## Компоненты

### Переиспользуемые компоненты
- **PromptCard** — карточка промпта (React.memo) с избранным
- **TemplateCard** — карточка шаблона (React.memo)
- **PromptEditor** — двухпанельный редактор с подсветкой (используется в `/editor` и `/profile/my-templates/create`)
- **PromptHighlight** — токенизатор синтаксиса промптов (React.memo)

### Навигация
- **Header** — логотип, навигация, поиск, иконки (React.memo)
- **Footer** — три колонки: бренд, навигация, информация
- **Breadcrumbs** — автоматические из URL
- **Skip-link** — доступность (skip to main content)

## Хуки

- `useFormValidation` — валидация форм (required, minLength, maxLength)
- `useDebounce` — debounce значений
- `useSearch` — поиск с debounce, саджестами, URL-параметрами и AbortController

## Доступность (Accessibility)

- Skip-link для перехода к основному контенту
- `aria-label` на навигационных элементах и формах поиска
- `aria-pressed` на кнопках фильтров
- `aria-invalid` / `aria-describedby` на полях форм
- `aria-live="polite"` на сообщениях статуса
- `role="alert"` на сообщениях об ошибках
- `role="switch"` на переключателях
- `aria-hidden` на декоративных иконках
- Метки `<label>` на всех полях ввода

## Производительность

- **React.memo** на PromptCard, TemplateCard, Header
- **useMemo** для вычислений фильтрации/сортировки
- **useCallback** для обработчиков событий
- **Debounce** поисковых запросов (300мс)
- **AbortController** для отмены предыдущих запросов
- **Critical CSS** инлайн через `experimental.inlineCss`
- **Static Site Generation** для статических страниц

```bash
npm test         # Unit-тесты
npx playwright test  # E2E-тесты
```
